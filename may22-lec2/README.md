# CMU 21-228 Discrete Mathematics — Lecture 2 Practice Problems
Problem 1 — set up recurrences like the lecture did
Count n-digit numbers using digits {1,2,3,4,5,6} with no two adjacent digits equal and ending even.
Define eₙ and oₙ. Find e₁ and o₁. Write the recurrences for eₙ₊₁ and oₙ₊₁. Compute e₂, o₂, e₃, o₃ by hand.

Problem 2 — same style, different constraint
Count n-digit strings using {1,2,3,4,5} with no two adjacent digits equal and ending in a prime (2,3,5).
Define pₙ and qₙ. Find base cases. Write recurrences. Compute for n=1,2,3.

Problem 3 — grid paths basic
A 3×3 grid. Paths go from top to bottom, each step goes Left or Right, always downward.
Write each path as a string. How many total paths? Write as C(n,k).

Problem 4 — subtraction method
A 4×4 grid has one missing edge — the leftmost edge in row 2.
Total paths minus bad paths. Compute the answer.

Problem 5 — product rule
Same 4×4 grid, same missing edge.
Count bad paths using: paths from top to start of missing edge × paths from end of missing edge to bottom.
Verify it matches what you subtracted in Problem 4.
